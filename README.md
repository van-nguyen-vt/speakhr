# SpeakHR – App luyện nói tiếng Anh cho HR

Web app cá nhân để luyện nói, phát âm (chấm từng âm kiểu ELSA), ngữ pháp và nghe — theo chủ đề công việc HR.

- **Chấm phát âm + giọng đọc:** Azure Speech, gói **Free (F0)**: 5 giờ chấm âm/tháng, hết thì tạm dừng, **không tính tiền**.
- **Hội thoại, soạn bài, sửa lỗi, báo cáo tuần:** Google Gemini API (gói miễn phí).
- **Dữ liệu:** lưu trong trình duyệt của điện thoại. Key KHÔNG nằm trong code này.

## Cài đặt (1 lần)

1. Bật GitHub Pages: repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: **main** / **(root)** → **Save**. Đợi 1–2 phút.
2. Trên iPhone, mở Safari: `https://van-nguyen-vt.github.io/speakhr/`
3. Bấm nút **Chia sẻ** → **Thêm vào MH chính**. Từ giờ mở app bằng icon SpeakHR (để dữ liệu không bị Safari xoá).
4. Trong app: ⚙️ → nhập key Gemini và Azure (có hướng dẫn trong app) → **Kiểm tra key**.

## Một buổi học (~50 phút)

1. Ôn tập cụm từ cũ (lặp lại ngắt quãng)
2. Âm của ngày — chấm từng âm, tô màu từng từ
3. Cụm từ & ngữ pháp của chủ đề
4. Luyện nghe nhiều giọng (Mỹ/Anh/Úc) + chép chính tả
5. Hội thoại đóng vai với Lukas (sếp người Đức) và các nhân vật khác
6. Sửa lỗi & nói lại
7. Tổng kết điểm

Sau buổi thứ 5 trong tuần: bài kiểm tra đọc cố định + báo cáo tuần.
